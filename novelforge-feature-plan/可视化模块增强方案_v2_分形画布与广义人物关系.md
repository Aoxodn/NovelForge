# 可视化模块增强方案 v2：分形画布与广义人物关系体系

> 基于 v1.1（节点=卷、三级下钻）的深度增强。
> 核心理念：**同一套画布引擎在三个粒度上递归使用**，人物关系体系通用化、可扩展，不绑定特定小说。

---

## 一、分形画布架构（三级递归）

```
┌──────────────────────────────────────────────────────────┐
│  L1 全书画布（StoryMap）                                   │
│  节点 = 卷    边 = 卷间剧情关系 + 跨卷人物轨迹              │
│  点击卷节点 ↓                                            │
├──────────────────────────────────────────────────────────┤
│  L2 卷内画布（VolumeMap）← 本次新增核心                    │
│  节点 = 章节  边 = 章间剧情关系 + 卷内人物关系网            │
│  左侧可视化画布（占 65%）| 右侧选中节点详情面板（占 35%）   │
│  点击章节节点 ↓                                          │
├──────────────────────────────────────────────────────────┤
│  L3 章节编辑器 + 右栏发展图（已有需求）                     │
│  左：正文编辑器  |  右：本章剧情发展图（场景/事件节点）      │
└──────────────────────────────────────────────────────────┘
```

三级共用同一套渲染内核（SVG 连线 + DOM 节点卡片 + view transform + 自动布局），仅数据源和节点粒度不同。

---

## 二、L1 全书画布增强（在现有基础上叠加人物层）

### 2.1 保持不变

- 卷节点（方形）、剧情线泳道、卷间边（顺序/因果/分支/汇合/伏笔）
- 自动布局（泳道分层）

### 2.2 新增：跨卷人物轨迹带

- 触发：人物在 ≥2 个卷有提及记录
- 视觉：从首出场卷到末出场卷，画一条 3px 半透明纵向带（opacity 0.25），颜色=人物角色色
- 多人物轨迹带垂直错开，间距 0.02（归一化坐标）
- 数据来源：`character_mentions` 聚合，纯渲染派生，不存库

### 2.3 新增：卷节点核心人物行

卷节点底部增加一行小圆头像（该卷提及 Top 4 人物），点击头像可跳转该人物视角。

## 三、L2 卷内画布（核心新增）

### 3.1 整体布局

```
┌──────────────────────────────────────┬───────────────────┐
│  工具栏：返回 │ 自动布局 │ 筛选       │  选中节点详情      │
│  ┌────────────────────────────────┐  │  ┌─────────────┐  │
│  │                                │  │  │ 章节标题     │  │
│  │    [章1]──→[章2]──→[章3]       │  │  │ 字数/状态    │  │
│  │      ↑       ↓ 因果            │  │  │ 章纲         │  │
│  │   [章5]←──[章4]                │  │  │ 出场人物     │  │
│  │      🠑人物关系层🠑              │  │  │ 关联伏笔     │  │
│  │   [叶文洁]─母女→[杨冬]          │  │  │ [打开正文]   │  │
│  │   [汪淼]──搭档→[史强]           │  │  └─────────────┘  │
│  └────────────────────────────────┘  │                   │
└──────────────────────────────────────┴───────────────────┘
```

- **左侧 65%**：可视化画布（章节节点 + 人物节点 + 两类边）
- **右侧 35%**：选中节点的详情面板（章节信息/人物信息，可切换）
- 不再是纯章节卡片列表

### 3.2 节点类型

#### 章节节点（方形，主节点）

| 属性 | 说明 |
|------|------|
| 标题 | 章节标题 |
| 字数 | 小字显示 |
| 状态色 | 草稿=灰、完稿=绿边框 |
| 节点类型 | 常规/转折/高潮/结局（chapters 预留字段，可手动标注） |
| 大小 | 固定，或按字数微变 |

#### 人物节点（圆形，叠加层）

| 属性 | 说明 |
|------|------|
| 大小 | r = 14 + log₂(本卷提及次数) × 2.5 |
| 颜色 | 角色类型：主角=蓝、配角=灰、反派=红、功能性=橙 |
| 位置 | 围绕出场章节节点辐射分布，不与章节节点重叠 |
| 显隐 | 工具栏"人物层"开关控制 |

### 3.3 边类型（卷内有两类边）

#### A. 剧情边（章节→章节）

复用 L1 的边类型语义，但粒度是章节：

| edge_type | 含义 | 视觉 |
|-----------|------|------|
| 0 顺序 | 叙事顺序（默认自动生成） | 实线灰 |
| 1 因果 | A 章事件导致 B 章 | 实线蓝 |
| 2 分支 | A 章引出多条线 | 虚线 |
| 3 汇合 | 多条线汇入 B 章 | 虚线 |
| 4 伏笔回收 | A 章伏笔，B 章回收 | 点线紫，带"伏笔"标签 |
| 5 平行叙事 | A、B 章同时发生（新增） | 双线 |
| 6 闪回/插叙 | B 章回忆 A 章事件（新增） | 反向箭头 + 虚线 |

#### B. 人物关系边（人物→人物）

见第四章广义关系体系。

#### C. 人物-章节出场边（辅助边）

人物节点与出场章节之间连浅灰细线（opacity 0.25），线粗按该章提及次数。可通过"出场边"开关隐藏。

### 3.4 卷内自动布局

章节节点按 `sort_order` 横向排列为主干（类似 L1 的主线泳道），但允许：
- 支线章节（node_type=支线或有分支边）向上/向下偏移
- 闪回章节放在主干下方
- 人物节点在章节节点周围的空白区域辐射排列

布局算法复用 L1 的泳道分层逻辑，将"卷"替换为"章节"，"剧情线"替换为"章内叙事线"。

### 3.5 右侧详情面板

选中章节节点时显示：
- 章节标题、字数、状态
- 章纲（chapters.summary，可编辑）
- 作者笔记（chapters.notes，可编辑）
- 本章出场人物列表（点击高亮画布上对应人物节点）
- 本章关联伏笔（活跃/已回收）
- "打开正文"按钮 → 跳转 L3 编辑器

选中人物节点时显示：
- 人物名、别名、角色
- 人物备注（可编辑）
- 本卷出场章节列表（点击跳转）
- 关联人物（关系边列表）

## 四、广义人物关系体系（通用、可扩展）

### 4.1 设计原则

- **不绑定题材**：适用于玄幻/都市/科幻/历史/悬疑/言情等所有类型
- **分类+子类型**：5 大类，每类下有若干子类型，作者也可自定义
- **大类定色，子类型定标签**：视觉上靠大类颜色区分，具体关系靠标签文字

### 4.2 五大关系类

#### 类 1：血缘/家族（色 #E1B98F 暖橙，实线无箭头）

| 子类型 | 说明 |
|--------|------|
| 父子/母子 | 直系长辈→晚辈 |
| 父女/母女 | |
| 兄弟/姐妹/兄妹/姐弟 | 平辈 |
| 祖孙/外祖孙 | 隔代 |
| 叔侄/舅甥/姑侄/姨甥 | 旁系 |
| 表亲/堂亲 | 远亲 |
| 夫妻/婚约 | 姻亲 |
| 其他亲属 | 自定义 |

#### 类 2：情感（色 #EAA7B2 粉，实线无箭头）

| 子类型 | 说明 |
|--------|------|
| 恋人/情侣 | 双向 |
| 夫妻 | 已婚 |
| 暗恋/单相思 | 单向箭头→被暗恋方 |
| 前任/旧爱 | |
| 情敌 | 双向，虚线 |
| 暧昧/知己 | |
| 其他情感 | 自定义 |

#### 类 3：社会关系（色 #5b8def 蓝，实线无箭头）

| 子类型 | 说明 |
|--------|------|
| 朋友/挚友 | |
| 损友/酒肉朋友 | |
| 师徒/师生 | 单向箭头→徒弟 |
| 主仆/上下级 | 单向箭头→下属 |
| 同僚/同事/同学/战友 | |
| 邻居/网友 | |
| 其他社会关系 | 自定义 |

#### 类 4：阵营/对立（色 #EA6668 红，虚线有箭头）

| 子类型 | 说明 |
|--------|------|
| 盟友/同伙 | 实线（覆盖红色为虚线规则） |
| 敌人/仇人/宿敌 | 双向虚线 |
| 背叛/被背叛 | 单向箭头→被背叛方 |
| 受害者/加害者 | 单向箭头→受害者 |
| 守护者/被守护者 | 单向箭头→被守护者 |
| 竞争/对手 | |
| 其他阵营关系 | 自定义 |

#### 类 5：叙事功能（色 #B56AD9 紫，点线有箭头）

这是元叙事层面的关系，不基于故事内社会关系，而是基于作者创作视角：

| 子类型 | 说明 |
|--------|------|
| 引路者/导师 | 引导主角成长，箭头→被引导者 |
| 绊脚石/对手 | 阻碍主角，箭头→被阻碍者 |
| 镜像/对照组 | 两个角色互为镜像，双向 |
| 催化剂 | 触发关键事件，箭头→被触发者 |
| 见证者/旁观者 | 见证关键事件，箭头→被见证者 |
| 继承者 | 传承某人意志/能力，箭头→继承者 |
| 其他叙事功能 | 自定义 |

### 4.3 数据模型

```sql
CREATE TABLE character_relations (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    from_char   INTEGER NOT NULL REFERENCES characters(id) ON DELETE CASCADE,
    to_char     INTEGER NOT NULL REFERENCES characters(id) ON DELETE CASCADE,
    rel_category INTEGER NOT NULL,   -- 1血缘 2情感 3社会 4阵营 5叙事
    rel_type    TEXT NOT NULL DEFAULT '',  -- 子类型名，如"母女""师徒""暗恋"
    label       TEXT NOT NULL DEFAULT '',  -- 自定义补充说明
    direction   INTEGER NOT NULL DEFAULT 0, -- 0双向 1单向(from→to)
    volume_id   INTEGER REFERENCES volumes(id) ON DELETE SET NULL,  -- 关系发生卷（可空=跨卷）
    created_at  TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
```

- `rel_category` 决定颜色和线型
- `rel_type` 是子类型名称（自由文本，下拉提供常用选项+允许自定义输入）
- `volume_id` 为 NULL 表示跨卷关系，在 L1 和 L2 都显示；有值则只在对应卷的 L2 画布显示

### 4.4 关系边在 L1 和 L2 的显示规则

| 关系范围 | L1 全书画布 | L2 卷内画布 |
|---------|------------|------------|
| volume_id=NULL（跨卷） | 显示（人物节点之间） | 显示 |
| volume_id=当前卷 | 不显示（粒度不够） | 显示 |
| volume_id=其他卷 | 不显示 | 不显示 |

L1 上人物节点是"跨卷核心人物"的精简层（只显示在 ≥2 卷出场的人物），L2 上显示该卷所有出场人物。

## 五、L3 章节发展图（已有需求，明确粒度）

章节编辑器右栏展示本章内部的发展图：

- 节点 = 场景/事件（用户手动创建，或从正文自动提取关键段落）
- 边 = 场景间的因果/顺序/转折
- 人物节点叠加：本章出场人物以小圆点显示在相关场景旁
- 这是最细粒度的可视化，与 L1/L2 同一套渲染内核

场景节点数据存在新增表 `chapter_scenes`（后续迭代，本次不做）。

## 六、同端多边路由优化（适用于所有三级画布）

### 6.1 类型分道 + 组内扇形

渲染前按 `(from, to)` 分组，组内按类别分配垂直偏移：

| 边类别 | 基准偏移 | 线型 |
|--------|---------|------|
| 顺序 | 0（中线） | 实线灰 |
| 因果 | +0.025 | 实线蓝 |
| 分支/汇合 | ±0.04 | 虚线 |
| 伏笔 | -0.04 | 点线紫 |
| 平行/闪回 | ±0.055 | 特殊线型 |
| 人物关系 | 人物层独立计算，不与剧情边争道 | — |

同类别多条边：组内序号 × 0.015 交替上下叠加。

### 6.2 标签外置

标签放在箭头前 15px 处，半透明白底，同组标签随边偏移同步错开。

### 6.3 超量合并

同端 >4 条剧情边时，多出的合并为 `+N` 徽标，点击展开。

## 七、筛选器体系（三级画布共用工具栏模式）

| 控件 | L1 | L2 | L3 |
|------|----|----|-----|
| 人物层显隐 | ✓（只显跨卷人物） | ✓（显本卷所有人物） | ✓（显本章人物） |
| 关系边显隐 | ✓ | ✓ | — |
| 出场边显隐 | — | ✓ | ✓ |
| 剧情线筛选 | ✓ | ✓（叙事线筛选） | — |
| 人物视角 | ✓ | ✓ | — |

**人物视角**：点击人物节点 → 高亮该人物出场的所有节点 + 关联人物，其余 opacity 0.15。顶部面包屑显示"人物视角：XXX [退出]"。

## 九、实施路径

| 阶段 | 内容 | 前端 | 后端 |
|------|------|------|------|
| P0 | 同端多边路由优化（§6） | ~50行 | 无 |
