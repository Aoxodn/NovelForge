## 〇、V1.0 → V1.1 变更摘要



| 项        | V1.0（章节 = 节点）        | V1.1（卷 = 节点）                                  |
| -------- | -------------------- | --------------------------------------------- |
| 节点粒度     | 每个章节 = 一个节点（几十上百个平铺） | **每个卷（故事阶段）= 一个节点**                           |
| 画布层级     | 单层                   | **三级：画布 (卷细纲) → 卷内 (细纲 + 章节) → 章节 (细纲 + 正文)** |
| 卷细纲入口    | 侧边栏右键「卷大纲…」（保留）      | **收敛到可视化模块**（画布节点抽屉 + 卷内视图），**移除侧栏入口**        |
| 连线对象     | chapters             | **volumes**（伏笔边额外支持章级锚点）                      |
| 全书总览 X 轴 | 章节顺序                 | **卷顺序**（节点 = 卷）                               |
| 章节归属     | 隐含 volume\_id        | 显式「手动选定加入」：拖拽归卷 + 添加弹窗                        |
| 删除语义     | 画布移除 ≠ 删章节           | **删除节点 = 删除卷**（显式确认，沿用现有删除卷流程）                |

## 一、背景与目标

### 1.1 痛点



1. **剧情只见局部**：单章视角看不到跨卷的因果链、多线并行与汇合。

2. **伏笔靠脑记**：埋设 / 回收关系散落在正文与笔记里，跨几十章极易断线。

3. **大纲是纯文本**：`project_info.outline` 只是自由文本，软件读不懂结构。

4. **（V1.0 设计缺陷）章节不是结构单元**：几十上百章平铺成节点，画布拥挤，且表达不出「一卷 = 一个故事阶段」这个真正重要的结构。

### 1.2 目标



| 层  | 名称       | 一句话                             |
| -- | -------- | ------------------------------- |
| L1 | 故事地图（画布） | **一卷一节点**，节点 = 故事阶段；双击节点下钻卷内    |
| L2 | 卷内视图     | 卷细纲编辑 + 本卷章节列表（手动加入 / 排序），点章节下钻 |
| L3 | 章节细纲     | 章细纲 + 作者笔记 + 正文入口 + 本章发展        |
| 支撑 | 全书总览     | 卷级泳道 / 伏笔总览（卷级 + 章级）/ 结构叠加      |
| 支撑 | 章节发展图    | 写作界面右栏展示当前章的「来龙去脉」              |

三者同源：**同一份 story graph 数据（卷节点 + 连线 + 章节归属），四种呈现尺度**（画布 / 卷内 / 章节 / 全书）。

### 1.3 非目标（本期不做）



* 全自由画布（Figma 式）—— 半自动布局。

* 在线协作、账号、云同步 —— 延续「本地优先、完全离线」。

* AI 作为必选依赖 —— 核心功能零 Token，AI 是节点级可选能力。

* 一章同时归属多个卷（多归属）——V1 唯一归属，V2 再评估。

### 1.4 设计原则（沿用）



1. **画布是视图，不是数据源**：正文 / 卷细纲 / 章纲仍是结构化存储的唯一事实源，画布双向同步、可随时关闭。

2. **连线必须带类型**：顺序 / 因果 / 分支 / 汇合 / 伏笔回收，五类。

3. **AI 放节点上，不放全局**。

4. **保持克制**：不破坏现有写作闭环；老项目打开自动兼容（迁移只追加）。

## 二、核心结构模型（本次修订核心）



```
第1层  故事地图（画布）       卷节点① ──因果──→ 卷节点② ──顺序──→ 卷节点③

&#x20;      （最外层 = 卷细纲）    （阶段① 6章）     （阶段② 7章）      （阶段③ 12章）

&#x20;                             ┄┄ 伏笔回收 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┘

&#x20;       │ 双击节点下钻                                    │

第2层  卷内视图              卷细纲编辑器  +  本卷章节列表

&#x20;       │ 点击章节下钻                                    │

第3层  章节细纲              章细纲 + 作者笔记 + 正文入口 + 本章发展（右栏）
```

**结构规则**



1. **一个节点 = 一个卷**：节点卡片显示 卷名 / 阶段序号（由 sort\_order 派生）/ 章节数 / 总字数 / 细纲摘要。

2. **章节唯一归属**：一章只能属于一个卷（`chapters.volume_id`），与目录树、导出、回收站天然兼容。

3. **「手动选定加入」**：把章节拖进节点（移动归属，复用现有跨卷 moveChapter）+ 卷内「添加章节」弹窗多选。

4. **卷细纲 =&#x20;**`volumes.summary`：不新增字段，编辑入口从侧边栏右键收敛到画布节点抽屉与卷内视图。

5. **删除节点 = 删除卷**：卷是结构单元，删除必须显式确认（沿用现有删除卷逻辑，含其下章节与版本）。

## 三、功能设计

### 3.1 L1・故事地图（卷节点画布）



* **半自动布局（泳道式分层，自动布局按钮触发）**：主线（主线弧 kind=0 或最长 顺序/因果 链）居中泳道 0、X 按阶段序推进；支线弧逐条排上方泳道（-1,-2,…）、暗线弧逐条排下方泳道（+1,+2,…）；无弧线卷沿连线挂靠最近邻泳道；非主线卷从分叉点向右外扩、同泳道同列自动避让。手动拖过的节点坐标保留（`map_x/map_y` 非空不再被覆盖）。

* **节点卡片**：卷名、阶段序号、章数、总字数、细纲摘要（`volumes.summary` 截取两行）。

* **连线**：`顺序 / 因果`（实线）、`分支 / 汇合`（虚线）、`伏笔回收`（青点线）—— 连接对象为**卷**；伏笔可锚定到具体章节（见 §4.2）。

* **交互**：


  * 单击节点 → 选中，右侧抽屉显示卷细纲编辑器（600ms 防抖保存 `volumes.summary`）；

  * **双击节点 → 下钻卷内视图**；

  * 拖节点边缘到另一节点 → 弹连线类型选择（伏笔需填 label、可选埋设章 / 回收章、弧线）；

  * 右键节点 → 编辑卷细纲 / 进入卷内 / 新建卷 / 删除卷；

  * 空白处右键 → 新建卷（与目录树联动）。

* **空态引导**：无卷时提示「从新建第一卷开始」；有卷无连线时提示「拖拽连接两个卷，标记阶段推进或伏笔」。

### 3.2 L2・卷内视图



* 面包屑：`故事地图 › 卷名`（可点返回画布）。

* 左区：**卷细纲编辑器**（与 3.1 同一数据源 `volumes.summary`，防抖保存）—— 即原「侧边栏右键 → 卷大纲」功能的整合位置。

* 右区：**本卷章节列表**（卡片：标题 / 状态色点 / 字数 / 章纲摘要）：


  * 拖拽卡片 = 卷内排序（复用 moveChapter 同卷逻辑）；

  * 从其他卷拖入 / 拖出 = 跨卷移动（「手动选定加入」的通道之一）；

  * 「＋ 添加章节」：弹窗多选其他卷章节 / 新建章节并入本卷；

  * 点击章节卡片 → 下钻第 3 层。

* 空卷提示：`（空卷，从「＋ 添加章节」或拖入其他卷章节开始）`。

### 3.3 L3・章节细纲



* 面包屑：`故事地图 › 卷名 › 章名`。

* **章细纲**（`chapters.summary`，600ms 防抖保存）：这一章写什么、关键冲突、结尾钩子。

* **作者笔记**（`chapters.notes`，不参与导出）：待改、伏笔提醒。

* **「打开正文」** → 跳转到现有三栏编辑器的该章（保持卷内视图组件挂载，可一键返回）。

* 该层与现有 InfoPanel 的「本章纲要 / 笔记」编辑是同一数据、两个入口（可视化模块内编辑后，右侧面板同步刷新）。

### 3.4 支撑视图・全书总览



* **剧情线泳道**：X 轴 = 卷顺序，节点 = 卷（按 `story_arcs` 分行，着色）；hover 高亮整条弧线；断档（弧线空缺的卷段）可辨识。

* **伏笔总览**：列表 / 网络，每条含 名称 / 埋设位置 / 回收位置 / 跨度（章序差）/ 状态 / 弧线；


  * 位置粒度：卷级（`from_node`）或 章级（`from_chapter_id` 非空时显示「第 N 卷・第 M 章」）；

  * 过滤：未回收 / 已回收 / 失效 / 按弧线；

  * **超期预警**：回收章序 − 埋设章序 > 阈值（默认 10 章，可配）→ ⚠。

* **结构总览**：三幕 / 起承转合阶段带叠加在卷轴上（一卷一阶段通常天然吻合）。

### 3.5 支撑视图・章节发展图（写作界面右栏）



* 位置：InfoPanel 新增「本章发展」卡（顺序：项目 → 当前章节 → 本章纲要 → 本章出场 → **本章发展** → 版本快照）。

* 内容（`get_chapter_story_context(chapterId)`）：


  * 本章在所属卷内的**前后章节**（各 ≤4，带连线类型）；

  * 所属卷的**入边**（上游卷 + 类型）与**出边**（下游卷 + 类型）；

  * **与本章相关的伏笔**：本章埋设、本章回收、所属卷级伏笔（活跃 / 已回收徽标）。

* 交互：点章节卡 → 故事地图定位高亮 / 跳章；点伏笔徽标 → 跳埋设章或回收章。

* 空态：未入图 / 无连线时提示「本章所属卷尚未建立连线，可在地图中连接」。

## 四、数据模型（V6 迁移）

### 4.1 设计决策



* **节点 = 卷，复用&#x20;**`volumes`**&#x20;表**：不建独立 node 表。卷 CRUD、章节归属（volume\_id）、细纲（summary）、导出、统计全部免费复用，无双数据源。

* **连线引用卷**：`story_edges.from_node / to_node → volumes.id`。

* **伏笔支持章级锚点**：伏笔边增加可空 `from_chapter_id / to_chapter_id`—— 卷级伏笔（NULL）与章级伏笔（精确到章）并存。

### 4.2 迁移 SQL（追加到 `db/migrations.rs`，不改历史迁移）



```
\-- V6：可视化写小说——卷节点化（画布=卷细纲，章节在卷内）

\-- ① 卷扩展：画布坐标（归一化 0..1，视口变化不失效）+ 节点类型（预留）

ALTER TABLE volumes ADD COLUMN map\_x REAL;

ALTER TABLE volumes ADD COLUMN map\_y REAL;

ALTER TABLE volumes ADD COLUMN node\_type INTEGER NOT NULL DEFAULT 0;  -- 0=常规 1=支线卷 2=番外（预留）

\-- ② 剧情线（总览泳道 / 伏笔归类载体）

CREATE TABLE IF NOT EXISTS story\_arcs (

&#x20;   id         INTEGER PRIMARY KEY AUTOINCREMENT,

&#x20;   title      TEXT NOT NULL,

&#x20;   kind       INTEGER NOT NULL DEFAULT 0,   -- 0=主线 1=支线 2=暗线

&#x20;   color      TEXT NOT NULL DEFAULT '',

&#x20;   summary    TEXT NOT NULL DEFAULT '',

&#x20;   created\_at TEXT NOT NULL DEFAULT (datetime('now','localtime')),

&#x20;   updated\_at TEXT NOT NULL DEFAULT (datetime('now','localtime'))

);

\-- ③ 连线：连接卷节点；伏笔可锚定到具体章节（可空=卷级）

CREATE TABLE IF NOT EXISTS story\_edges (

&#x20;   id               INTEGER PRIMARY KEY AUTOINCREMENT,

&#x20;   from\_node        INTEGER NOT NULL REFERENCES volumes(id) ON DELETE CASCADE,

&#x20;   to\_node          INTEGER NOT NULL REFERENCES volumes(id) ON DELETE CASCADE,

&#x20;   edge\_type        INTEGER NOT NULL,       -- 0=顺序 1=因果 2=分支 3=汇合 4=伏笔回收

&#x20;   arc\_id           INTEGER REFERENCES story\_arcs(id) ON DELETE SET NULL,

&#x20;   from\_chapter\_id  INTEGER REFERENCES chapters(id) ON DELETE SET NULL,  -- 伏笔埋设章（可空=卷级）

&#x20;   to\_chapter\_id    INTEGER REFERENCES chapters(id) ON DELETE SET NULL,  -- 伏笔回收章（可空=卷级）

&#x20;   label            TEXT NOT NULL DEFAULT '',   -- 因果说明 / 伏笔内容

&#x20;   status           INTEGER NOT NULL DEFAULT 0, -- 伏笔：0=活跃 1=已回收 2=失效；其余类型固定 0

&#x20;   sort\_order       INTEGER NOT NULL DEFAULT 0,

&#x20;   created\_at       TEXT NOT NULL DEFAULT (datetime('now','localtime')),

&#x20;   updated\_at       TEXT NOT NULL DEFAULT (datetime('now','localtime')),

&#x20;   CHECK (from\_node != to\_node)

);

CREATE INDEX IF NOT EXISTS idx\_edges\_from ON story\_edges(from\_node);

CREATE INDEX IF NOT EXISTS idx\_edges\_to   ON story\_edges(to\_node);

CREATE INDEX IF NOT EXISTS idx\_edges\_arc  ON story\_edges(arc\_id);
```

### 4.3 字段口径



| 字段                                            | 说明                               |
| --------------------------------------------- | -------------------------------- |
| `volumes.map_x / map_y`                       | 画布坐标，归一化 0..1；NULL = 未排布（自动布局覆盖） |
| `volumes.node_type`                           | V1 仅 0 = 常规；支线卷 / 番外为预留扩展        |
| `chapters.volume_id`                          | 既有字段，即章节所属节点（唯一归属）               |
| `volumes.summary`                             | 既有字段，即卷细纲（画布节点抽屉 / 卷内视图编辑）       |
| `story_edges.edge_type`                       | 预留扩展位（如未来「时间跳跃」边 = 5）            |
| `story_edges.from_chapter_id / to_chapter_id` | 仅伏笔边有意义；非空 = 精确到章的埋设 / 回收位置      |
| `story_edges.status`                          | 仅伏笔边有意义；回收 = 手动标记或回收章完稿时建议       |

### 4.4 兼容性



* 迁移只追加，`PRAGMA user_version` 门控，旧项目打开自动补表。

* `volumes` 新列均有默认值，现有读写路径零改动。

* `chapters.volume_id` 语义不变，目录树、回收站、导出、码字统计全部不动。

* 侧边栏「卷大纲」入口移除**只删 UI 入口**，`volumes.summary` 数据与导出行为不变。

## 五、状态机

### 5.1 卷状态

卷无独立状态字段：阶段由 `sort_order` 与节点连线表达；「是否已完结 / 进行中」由卷内章节完成度（`status=1` 章数占比）派生展示，不落库。

### 5.2 章节状态（沿用）



```
status 0=草稿(空心点) ── 完稿 1=实心点
```

画布 / 卷内 / 目录树的色点同源 `chapters.status`，不新增枚举。

### 5.3 伏笔状态机（沿用 V1.0）



```
创建伏笔边(埋设) ──→ 活跃(默认) ──→ 已回收(回收章完稿提示 / 手动标记)

&#x20;                       │

&#x20;                       └──→ 失效(作者标记，剧情废弃)
```



* 回收建议：`to_chapter_id`（或回收卷内任一章）`status=1` 时，UI 提示「是否标记已回收」。

* 超期预警：`回收章序 − 埋设章序 > 阈值(默认10)` → 总览与右栏标 ⚠。

## 六、AI 介入（本地规则优先，零 Token）



| 能力      | 输入                | 输出                    | 实现                                      |
| ------- | ----------------- | --------------------- | --------------------------------------- |
| 卷细纲扩写   | 卷内各章 summary 聚合   | 本卷目标 / 冲突 / 钩子建议      | 本地规则：章节梗概拼接 + 模板结构化                     |
| 卷间连贯性检查 | 卷的入边 / 出边 + 首尾章实体 | 阶段衔接冲突提示              | 复用 characters/locations + mentions 精确匹配 |
| 伏笔追踪    | 卷 / 章节            | 相关伏笔列表（埋设 / 活跃 / 未回收） | 直接查 story\_edges (edge\_type=4)         |
| 本章核对    | 本章实体 + 所属卷细纲      | 章纲与卷纲一致性提示            | 关键词交集 + mentions                        |

原则：全部本地完成，符合 PRD「AI 可选、核心功能零 Token」；未来插件化接大模型时命令签名不变。

## 九、决策记录（V1.1）



| 决策点   | 选择                         | 理由                                    |
| ----- | -------------------------- | ------------------------------------- |
| 节点模型  | **卷 = 节点**（复用 volumes）     | 章节是内容单元，卷是结构单元；复用卷 CRUD / 章节归属 / 细纲字段 |
| 章节归属  | **唯一归属**（volume\_id）       | 兼容目录树 / 导出 / 回收站；避免多归属复杂度（V2 再评估）     |
| 伏笔粒度  | **支持章级锚点**（可空列）            | 卷级概览 + 章级精确，成本极低                      |
| 卷细纲入口 | **收敛到可视化模块**，移除侧栏右键        | 功能整合、单一入口；数据字段不变                      |
| 删除语义  | **删除节点 = 删除卷**（显式确认）       | 卷是结构单元，不留「空节点」歧义                      |
| 布局    | 半自动（sort\_order 主线 + 手动微调） | 全自由画布门槛过高                             |
| 坐标存储  | 归一化 0..1                   | 视口尺寸变化不失效                             |

## 十、待确认（默认已采纳，可调整）



1. **章节唯一归属** —— 默认采纳；如后续需要「一章同时出现在多个节点」，V2 引入 `node_chapters` junction 表，不动本版数据结构。

2. **伏笔章级锚点** —— 默认采纳（字段已预留）。

3. **卷节点类型**（支线卷 / 番外）—— V1 仅 `0=常规`，枚举预留。

4. **时间线视图口径** —— 默认基于卷 / 章节顺序（结构时间线）；正文时间表达式已随 V3 废弃 `timeline_markers`，如需恢复另行评估。
